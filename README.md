# Portfolio
Static site, no build step. Publish with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
- Styles are inlined in each page (the CSS block in `<head>`); edit it in all pages, or move it to a shared file.
- Replace `Your Name`, email and social links in every page.
- Replace a placeholder with an image: swap `<div class="ph" data-label="…"></div>` for `<img src="assets/your-image.jpg" alt="…">`
- Duplicate `project.html` for each new project and link it from `index.html` and `work.html`.
